Lab #2: Cupcake Collector
A game where a cute character eats cupcakes.

In most 2D games, characters and objects are represented using sprites. A sprite is a 2D image used to represent a character, enemy, collectible, or other game object.

Create a simple platform game in which a cute character:
- Moves left and right
- Jumps onto platforms
- Collects cupcakes
- Earns points for each cupcake collected

Game:
- Use the LEFT and RIGHT arrows to move
- Use the UP arrow to jump
- Collect cupcakes by touching with the character
- Add a point to your score by collecting a cupcake
